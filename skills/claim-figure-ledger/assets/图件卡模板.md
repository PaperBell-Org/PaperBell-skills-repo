## 合规检查清单

### 内容与版式

- [ ] 每个子图都有存在的理由，可有可无的已删
- [ ] 图里没有解释性长文字；说明性的话已移入图注
- [ ] 表格没有嵌进图里，改成正文表或补充表
- [ ] 图内文字只有坐标轴、色标、图例、子图字母和必要标签
- [ ] 已看过目标期刊同类论文的画法

### 地图（不是地图就整节取消）

- [ ] 坐标系 / 投影写在 `projection`，与分析所用一致；面积比较用等积投影
- [ ] 比例尺、指北针按需要添加；小比例尺全球图可省略指北针
- [ ] 边界数据来源写进图注或 Methods

### 中国地图合规（不涉及中国国界就整节取消）

- [ ] 底图来自国家标准地图服务等官方来源，未自行编辑国界几何；`basemap` 已填
- [ ] 审图号已标注在图上或图注中（`review_number`）；没有审图号的已告知作者
- [ ] 南海诸岛：有南海诸岛插图（或主图已完整包含南海），断续线画全，与官方标准地图一致
- [ ] 台湾、香港、澳门的表达与官方标准地图一致；专题数据缺失时标“资料暂缺”，不用会被理解为不同政治地位的颜色
- [ ] 国外通用边界数据（如全球行政区划库）没有直接用作中国国界
- [ ] 投稿期刊对地图的政策已查（以期刊要求为准）

### 色彩

- [ ] 一种颜色只表示一种含义，跨图一致
- [ ] 做过色盲模拟；没有红绿并用，没有彩虹色标
- [ ] 有序变量用有序色标，正负发散用发散色标并以 0 或有意义的参照值为中点
- [ ] 显著性不用颜色表示方向（可用实心 / 空心）

### 字体、尺寸与导出

- [ ] 宽度按目标期刊：Nature 单栏 89 mm、双栏 183 mm；子图按最终印刷尺寸绘制
- [ ] 字体与字号按期刊要求（Nature 系列常用无衬线字体，具体字号以期刊要求为准）
- [ ] 导出矢量格式（PDF / SVG / EPS）并嵌入字体；位图分辨率以期刊要求为准
- [ ] 坐标轴带单位；无多余背景网格

### 可复查性与图注

- [ ] 源数据可导出：每个子图背后的数值表已导出（CSV / XLSX），路径写在 `data_path`
- [ ] 图中每个数字都能追到结果表或结论卡
- [ ] 图注写清样本量（人数、单元数、天数等）和区间的种类（如 95% CI、聚类层级）
- [ ] 图注写清参照组、时间窗口和排除了哪些样本
- [ ] 输出文件可由 `script_path` 从 `data_path` 重新生成
